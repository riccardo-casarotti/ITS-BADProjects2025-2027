🔗 Microsoft 365 & Power Platform: Automation via Power Automate, SharePoint management, and integration of the Office 365 ecosystem.

BAD - Business Application Developer (2025-2027)

Benvenuti nel repository dedicato ai progetti e alle esercitazioni del corso BAD (Business Application Developer) per il biennio 2025-2027. Questo spazio raccoglie l'evoluzione delle mie competenze nello sviluppo di soluzioni software orientate al business e alla gestione dei dati.

📌 Panoramica del Corso

Il percorso formativo si focalizza sull'integrazione di sistemi ERP, automazione dei processi aziendali e analisi dei dati, preparando alla figura del Data Manager e dello sviluppatore di applicazioni Enterprise.

🛠 Tech Stack & Competenze

Il repository è suddiviso in sezioni basate sui moduli principali trattati durante l'anno:

🗄️ SQL & Data Management: Progettazione database relazionali, query complesse e gestione dell'integrità dei dati.
🐍 Python: Sviluppo di script per l'automazione, manipolazione dati e logica applicativa.
🔷 C# / .NET: Programmazione Object-Oriented finalizzata alla creazione di software robusti e integrazioni custom.
☁️ Azure: Sviluppo di soluzioni cloud-native, incluse Azure Functions, Azure Repos e pipeline CI/CD con Azure Pipelines.
🚀 Microsoft Dynamics 365 Business Central: Sviluppo in ambiente ERP (linguaggio AL), gestione flussi contabili e di magazzino.
🔗 Microsoft 365 & Power Platform: Automazione tramite Power Automate, gestione SharePoint e integrazione dell'ecosistema Office 365.
